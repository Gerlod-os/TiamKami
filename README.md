# 🎮 TianKami Roguelike Database

Личная база рогаликов стримера [TianKami](https://www.twitch.tv/tiankami).

## 📋 Описание

Каталог из 400+ рогаликов, которые проходил, дропал или обозревал стример TianKami. Каждая игра содержит:
- Оценку по шкале от 1 до 10 (💎 — гранёный кристалл, символ ценности игры)
- Статус прохождения (Пройдено / Дропнуто 💀 / Обзор / Жду релиз / В процессе)
- Жанры, особенности, сеттинг, сложность
- Часы наигранного времени
- Личные заметки Тиана
- Ссылки на YouTube-прохождения
- Бейдж 🏆 для игр-участников шоу «Мастер Игорей»

## 🎨 Стиль

Сайт выполнен в фирменном стиле TianKami:
- Тёмная палитра (#0a0e1a)
- Неоновые акценты: фиолетовый (#a855f7) и зелёный (#22c55e)
- Шрифты: Inter (основной) + JetBrains Mono (цифры)
- Карточки с неоновым свечением при наведении

## 🚀 Технологии

- HTML5
- Vanilla JavaScript (без фреймворков)
- Tailwind CSS через CDN
- Данные: `data/games.json`
