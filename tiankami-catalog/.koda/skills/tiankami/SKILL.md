
## Структура данных

### Мастер-таблица Google (ID в `src/config/dataSources.js`)

Вкладки: Статистика (gid=1211457087), **Все рогалики** (gid=0 — лист игр), **Подборки от Тиана** (gid=1239313701), остальные не используются.

Лист «Все рогалики» (TSV, ~440 строк):

- A — пустая; B — картинка; C — название со **вшитой гиперссылкой на Steam** (B:C объединены)
- далее: Жанр, Особенности, Сеттинг, **Сложность (G:H — шкала + значение, 10-балл)**, Наиграно (часы), Статус, **Прогресс (K:L — шкала + %)**, **Оценка (M:N — шкала + значение, 10-балл)**, Дата выхода, Когда играл, Примечания, YouTube, Проводил МИ (TRUE/FALSE), Выпуск МИ
- МИ = «мастер Игорей» — турнир стримеров
- Даты DD.MM.YYYY — только через `parseRuDate`
- Статус «Жду релиз» → «Жду релиза» (`normalizeStatus`)

Лист «Подборки от Тиана» (gviz CSV): колонки «гуляют» — парсер `normalizeCollections` работает **ПОСТРОЧНО**, не переписывать на колоночный. У «ЗОЛОТОГО СПИСКА» рангов нет.

### Гиперссылки (ключевая особенность)

TSV-экспорт теряет гиперссылки. Настоящие URL достаются из копии таблицы через Sheets API (`valueRenderOption=UNFORMATTED_VALUE`):

- Steam: `=HYPERLINK` в колонке C оригинала → Apps Script копирует в копию → sync читает из колонки U (`row[18]`)
- YouTube/МИ: sync читает из колонок V и W (`row[19]`, `row[20]`), фильтрует по `isYouTubeUrl`
- В JSON хранятся: `steamAppId`, `youtube`, `miVideo`
- Браузер (`loadData.js`) может достать гиперссылки из оригинала через `valueRenderOption=FORMULA` как fallback

### Два источника

1. **Оригинал** (`SPREADSHEET_ID`) — TSV для сайта (SWR-обновления).
2. **Копия** (`COPY_SPREADSHEET_ID`) — ссылки для `npm run sync`. В копию Apps Script автоматически копирует гиперссылки из оригинала.

## API-ключи

1. **Браузерный** `VITE_SHEETS_API_KEY` — Websites-ограниченный, для сайта. Из Node всегда 403 — это нормально.
2. **Серверный** `SHEETS_API_KEY_SERVER` — без ограничений, секрет, только для sync. Без `VITE_` → не в бандле.

Оба в `.env` (в `.gitignore`). sync-скрипт читает `.env` вручную (`import.meta.env` только в Vite).

## Жёсткие границы

- 🚫 Steam API — никогда, только CDN по appid
- 🚫 noembed-лимит: 20 за сессию (`NOEMBED_LIMIT` в `loadData.js`)
- 🚫 Никаких автоповторов; всё кэшируется (Twitch 5мин/24ч, авторство YouTube — бессрочно)
- 🚫 Личные данные — только в `src/config/branding.js`; источники и ключи — только в `src/config/dataSources.js`
- 🚫 Не переписывать построчный парсер подборок на колоночный
- 🚫 Не предлагать удалять `vite.config.js` / `package.json`
- Комментарии в коде — на русском; заглушек в коде не оставлять

## Известные ловушки

- `import.meta.env` только в Vite — в Node читать `.env` вручную
- Статические ESM-импорты поднимаются вверх — конфиг с ключами импортировать динамически (`await import`)
- `sheets.googleapis.com` может быть недоступен из РФ (DPI) — таймаут + ретраи; сайт не должен зависеть от него в рантайме
- Первый лист таблицы — «Статистика», в Sheets API указывать лист явно (`'Все рогалики'!A:Z`)
