# Tiankami Catalog — Каталог рогаликов

Сайт-визитка канала [Tiankami](https://twitch.tv/tiankami): база рогаликов с оценками, прогрессом и заметками стримера. Данные автоматически подтягиваются из Google Таблицы.

## Быстрый старт

```bash
npm install    # один раз
npm run dev    # запуск для разработки
npm run build  # сборка для публикации (включая SEO-страницы)
npm run sync   # вручную обновить локальные данные из таблицы
```

## Как это работает

1. При открытии сайт **мгновенно** показывает данные из кэша браузера или локальных файлов `src/data/*.json`.
2. В фоне тихо сверяется с Google Таблицей (не чаще раза в 15 минут). Если таблица изменилась — страница обновляется сама, без перезагрузки.
3. Кэш живёт 6 часов, потом обновляется.

## Два источника данных

Сайт использует **две таблицы** Google Sheets:

1. **Оригинал** (`SPREADSHEET_ID` в `src/config/dataSources.js`) — откуда сайт загружает TSV-данные для SWR-обновлений в браузере.
2. **Копия** (`COPY_SPREADSHEET_ID` в `scripts/sync-data.js`) — откуда `npm run sync` загружает Steam, YouTube и МИ ссылки. В копию Apps Script автоматически копирует гиперссылки из оригинала.

Между таблицами нет прямой связи — копия не меняется при редактировании оригинала. Синхронизация ссылок происходит через Google Apps Script (отдельный скрипт в копии таблицы).

## Как сменить Google Таблицу

Всё в двух файлах: **`src/config/dataSources.js`** и **`scripts/sync-data.js`**

1. Открой свою таблицу → «Файл» → «Сведения» → скопируй ID из URL (часть между `/d/` и `/edit`).
2. В `dataSources.js` замени `SPREADSHEET_ID` (это ID оригинала, откуда сайт берёт TSV-данные).
3. Создай **копию** таблицы и в `scripts/sync-data.js` замени `COPY_SPREADSHEET_ID` на ID копии.
4. Проверь `GAMES_SHEET_NAME` (точное имя листа с играми) и `COLLECTIONS_SHEET_NAME` (точное имя листа с подборками).
5. Сделай `npm run sync` и проверь, что в `src/data/*.json` появились данные.

Старый кэш у посетителей сбросится сам — ключи кэша привязаны к ссылке таблицы.

## API-ключ Google (ссылки на YouTube/МИ и обложки Steam)

Гиперссылки в опубликованных таблицах при экспорте превращаются в текст. Чтобы сайт видел настоящие URL, нужен бесплатный ключ Sheets API:

1. Зайди на [console.cloud.google.com](https://console.cloud.google.com) под своим Google-аккаунтом.
2. «Выбрать проект» → «Новый проект» → любое имя → «Создать».
3. В поиске сверху набери **Google Sheets API** → открой → «Включить».
4. Меню (☰) → «APIs & Services» → «Credentials» → «+ Create Credentials» → **API key**.
5. Скопируй ключ. Сразу нажми «Restrict key»:
   - **API restrictions** → Restrict key → выбери только _Google Sheets API_;
   - **Website restrictions** → добавь домен сайта (например `tiankami.vercel.app/*` и `localhost:5173/*` для разработки).
6. Создай файл `.env` в корне проекта (он не попадает в git):
   ```
   VITE_SHEETS_API_KEY=твой_ключ
   ```
7. Для Vercel: Settings → Environment Variables → добавь ту же переменную.

Без ключа сайт полностью работает — просто ссылки на плейлисты/МИ будут видны только если владелец вставил их обычным текстом, а обложки игр будут заглушками.

### Второй ключ для sync-скрипта (обложки Steam)

Браузерный ключ ограничен по домену и **всегда даёт 403 из Node** (у серверных запросов нет реферера). Чтобы `npm run sync` записывал в `games.json` Steam-appid (из него строятся обложки и ссылки на Steam), создай **второй** ключ:

1. Console → Credentials → **+ Create Credentials** → API key.
2. Ограничь только по API (Google Sheets API), **Application restrictions: None**.
3. Этот ключ — секрет: не публикуй его и не добавляй в Vercel.
4. Впиши в `.env`:
   ```
   SHEETS_API_KEY_SERVER=второй_ключ
   ```
5. `npm run sync` — в `games.json` появятся `steamAppId`, `youtube` и `miVideo` у игр со ссылками.

Без второго ключа sync тоже работает — просто ссылки не появятся.

Ссылки на YouTube фильтруются: показываются только видео с канала стримера (проверка по имени канала, настраивается в `src/config/branding.js`).

## Как передать сайт другому человеку

Все личные данные — в **`src/config/branding.js`**: название канала, Twitch-логин, ссылки на соцсети, имя YouTube-канала. Новому владельцу нужно:

1. Поменять значения в `branding.js` на свои.
2. Заменить `SPREADSHEET_ID` в `dataSources.js` на свою таблицу (или договориться с текущим владельцем таблицы — доступ на чтение уже открыт).
3. Создать копию таблицы, установить Apps Script для синхронизации ссылок, и заменить `COPY_SPREADSHEET_ID` в `scripts/sync-data.js`.
4. Создать свой API-ключ (см. раздел выше) — старый ключ привязан к домену и проекту прежнего владельца.
5. Обновить `src/data/*.json` через `npm run sync`.

## Структура мастер-таблицы

Таблица: вкладки «Статистика», **«Все рогалики»** (лист игр, gid=0), **«Подборки от Тиана»**, Топ по оценке, Экшен, Карточные, Bullet Hell, Вампирлайки, Будущие новинки, Дропнутые новинки. Сайт использует только два выделенных листа.

Лист «Все рогалики» (колонки):
| Колонка | Содержимое |
|---|---|
| A | пустая |
| B | картинка игры |
| C | название со вшитой гиперссылкой на Steam (заголовок «Название» объединён на B:C) |
| далее | Жанр, Особенности, Сеттинг, Сложность (сдвоенная: шкала + значение), Наиграно (часы), Статус, Прогресс (сдвоенная: шкала + %), Оценка (сдвоенная: шкала + значение), Дата выхода, Когда играл, Примечания, YouTube прохождение, Проводил МИ (TRUE/FALSE), Выпуск МИ |

Особенности:

- МИ = «мастер Игорей» — многопользовательский интерактив, турнир стримеров.
- Статус «Жду релиз» автоматически приводится к «Жду релиза».
- «ЗОЛОТОЙ СПИСОК» в подборках — без рангов (числа в таблице игнорируются).
- Гиперссылки при экспорте теряются: Steam-appid, YouTube и МИ-ссылки достаются через Sheets API из **копии** таблицы при `npm run sync`.

## Структура проекта

```
src/
  config/        брендинг и источники данных (всё настраиваемое здесь)
  utils/         загрузка, парсинг, даты, слаги, storage, swr
  components/    карточки, модалки, виджеты, маскоты
  pages/         Главная, Каталог, Подборки, Расписание, О канале, Игра
  data/          локальные копии данных (обновляются через npm run sync)
scripts/
  sync-data.js   скачивание таблицы в JSON (читает из копии)
  prerender.mjs  генерация SEO-страниц при сборке
```

## Защита от блокировок API

Все внешние запросы кэшируются: статус Twitch — 5 минут, аватарка — сутки, проверка авторства YouTube — бессрочно (один раз на ссылку). Steam не запрашивается вовсе — обложки берутся напрямую с его CDN по appid.
