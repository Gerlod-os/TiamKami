# Tiankami Catalog — Каталог рогаликов

Каталог рогаликов (roguelike/roguelite) для стримера Tiankami. Оценки, прогресс, заметки по всем пройденным играм.

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Синхронизация данных

Данные загружаются из Google Sheets (TSV). Для ручного обновления локальных файлов:

```bash
npm run sync
```

Результат сохраняется в `src/data/games.json` и `src/data/collections.json`.
