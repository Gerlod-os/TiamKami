# PROJECT_BRIEF — Tiankami Catalog

> Источник правды о проекте. При противоречиях приоритет: этот файл > README.md > AGENTS.md.
> Обновлён: сентябрь 2026.

## 1. Суть проекта

Сайт-визитка Twitch-канала Tiankami: атмосферная база рогаликов (~440 игр) с личными оценками, прогрессом и заметками стримера. Назначение: зрители узнают «во что поиграть», видят плейлисты прохождений и подборки; стример получает систематизированную библиотеку и бренд канала.

Дизайн-концепция: «уютный хардкор» — тёмная тема (#121212 → #1a1a2e), пастельные акценты (розовый #FFB6C1, фиолетовый #C9A0DC, голубой #A0C4FF), скругления 12–16px, свечение при наведении. Шрифты: Nunito (заголовки), Inter (текст). Маскоты: свои SVG-персонажи (геймпад с рожицей, герой в капюшоне) — в `src/assets/`.

## 2. Технический стек (фиксированный)

- Vite 8 + React 19 + Tailwind CSS v3
- React Router v7, PapaParse, react-icons
- Oxlint (не ESLint)
- Деплой: Vercel (SPA-rewrite в vercel.json). Сайт должен быть доступен из России.

## 3. Архитектура данных (КЛЮЧЕВОЕ)

**Два источника:** сайт использует **оригинал** и **копию** таблицы Google Sheets.

**Оригинал** (`SPREADSHEET_ID` в `src/config/dataSources.js`):

- лист «Все рогалики»: `gid=0`, экспорт TSV для SWR-обновлений в браузере
- гиперссылки доступны через Sheets API (`valueRenderOption=FORMULA`)

**Копия** (`COPY_SPREADSHEET_ID` в `scripts/sync-data.js`):

- Apps Script автоматически копирует гиперссылки из оригинала
- `npm run sync` читает из копии через Sheets API (`valueRenderOption=UNFORMATTED_VALUE`, колонки C:W)
- sync записывает в `games.json` все три поля: `steamAppId`, `youtube`, `miVideo`

Гиперссылки теряются при экспорте TSV — достаются из копии через Sheets API. В JSON хранятся все три поля: `steamAppId`, `youtube`, `miVideo`.

Стратегия stale-while-revalidate (`src/utils/loadData.js`):

1. МГНОВЕННО: память → localStorage-кэш (ключ привязан к URL таблицы хэшем) → локальный `src/data/*.json`.
2. В ФОНЕ: сверка с таблицей (не чаще раза в 15 минут).
3. Если отличается — обновить кэш и вызвать `onUpdate(свежие)` → интерфейс обновляется без перезагрузки.
4. TTL кэша 6 часов. При недоступности localStorage — работа из памяти и локального JSON.
5. При фоновой проверке восстанавливаем `steamAppId` + обложки из старой версии, если Sheets API недоступен (Websites-ограничение ключа).

Гиперссылки (YouTube-плейлисты, МИ, Steam) достаются из копии через Sheets API (`valueRenderOption=UNFORMATTED_VALUE`). Ключей два: **браузерный** `VITE_SHEETS_API_KEY` (Websites-ограниченный, публичный по дизайну; из Node всегда 403) и **серверный** `SHEETS_API_KEY_SERVER` (секрет, только для sync-скрипта, не попадает в клиентский бандл). YouTube-ссылки фильтруются «только канал стримера» (noembed, кэш авторства бессрочный, лимит 20 проверок за сессию).

## 4. Реализовано (проверено сборкой и линтером)

- Загрузка SWR + локальный фолбэк + `npm run sync` (sync обогащает games.json steamAppId через серверный ключ; без него — корректная деградация)
- Каталог: фильтры (жанр/статус/оценка/сложность/часы/год/МИ), сортировка (включая дату через parseRuDate), живой поиск, уникальные слаги-ключи
- Модалка игры (Escape, блокировка скролла) + отдельная страница с мета-тегами и cleanup
- Подборки с рангами (1–10; у «ЗОЛОТОГО СПИСКА» рангов нет: владелец уберёт числа из таблицы, парсер дополнительно гасит их принудительно) и ссылками на игры
- Ссылки игр: YouTube-плейлист, выпуск МИ и страница Steam (кнопки на странице игры; различение плейлист/МИ по подписи формулы)
- Маскоты в UI: SVG-персонажи в шапке (геймпад) и футере (герой) через `src/config/mascots.js` флаг `USE_ORIGINAL` 
- Twitch-виджет: аватарка + Live-бейдж + название стрима через DecAPI (статус кэш 5 мин, аватар 24 ч)
- «Секретка» (FxPanel): звуки (Web Audio, синтез, ноль файлов) + кастомный курсор, по умолчанию выключены, кнопка в правом нижнем углу
- Кастомный скроллбар (CSS), CSS-тултипы (`data-tip` атрибут) на оценке/часах/статусе
- SEO-пререндер: `npm run build` генерирует index + catalog + collections + 440 страниц игр + sitemap.xml (443 URL) + robots.txt (`scripts/prerender.mjs`)
- Мобильное меню-гамбургер, доступность (role, tabIndex, Escape, focus-visible)
- Конфиги: `src/config/branding.js` (всё личное) + `src/config/dataSources.js` (таблица, API-ключ)
- Яндекс.Метрика: счётчик `98370656` интегрирован в корневой layout (`src/components/YandexMetrika.jsx`), отслеживает просмотры страниц и события, работает в production-сборке.

## 5. Не реализовано (бэклог, по согласованию)

- Пагинация каталога: отложена (~440 игр рендерятся нормально).
- Кастомный курсор как отдельная фишка — реализован внутри FxPanel.
- Расписание стримов: страница-заглушка; Twitch API требует токен — отложено.
- Звуковая кнопка обратной связи — базовые звуки есть в FxPanel, богатые эффекты не делались.

## 6. Правила данных (жёсткие)

- Даты DD.MM.YYYY — только через `parseRuDate` (`src/utils/date.js`).
- МИ = «мастер Игорей» — многопользовательский интерактив, турнир стримеров. Признак — колонка «Проводил МИ» (TRUE/FALSE), видео — «Выпуск МИ».
- Статусы: владелец пишет «Жду релиз» — `normalizeStatus` приводит к «Жду релиза»; также встречается «В процессе».
- Ссылки из таблицы валидны только если начинаются с http(s) (`isUrl`); тексты-заглушки («Ссылка на плейлист») отфильтровываются автоматически.
- YouTube-ссылки показываются только с канала стримера (проверка author_name через noembed).
- Steam: никаких запросов к API — только CDN-обложка и ссылка по appid из гиперссылки в названии.
- Парсер подборок работает ПОСТРОЧНО (колонки листа «гуляют») — не переписывать на колоночный.

## 6.1. Вспомогательные файлы в корне проекта

- `GOOGLE_SHEETS_SCRIPT.txt` — скрипт для Google Apps Script, который автоматически копирует гиперссылки из оригинальной таблицы (лист «Все рогалики») в копию (используется `npm run sync`). Без этого скрипта копия не обновляется, а гиперссылки не попадают в `games.json`.
- `PLAN.md` — дорожная карта развития проекта: перечислены запланированные фичи, приоритеты и примерные сроки. Используется для координации работ.

## 7. Защита от блокировок API (урок: Steam заблокировал пользователя за парсинг)

- Все внешние запросы кэшируются: Twitch-статус 5 мин, аватар 24 ч, авторство YouTube — бессрочно.
- Лимит noembed-проверок за сессию: 20.
- Sync-скрипт — только вручную, 2 запроса за запуск.
- Никаких автоповторов и автопоиска по названию.
