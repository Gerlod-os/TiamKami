# AGENTS.md

Контекст для ИИ-агентов.

Источник правды — `PROJECT_BRIEF.md`, инструкция для людей — `README.md`.

При противоречиях: `PROJECT_BRIEF.md` > `README.md` > этот файл.

---

## 🎯 Приоритеты (от высшего к низшему)

1. **Безопасность** — не предлагай изменения, которые могут сломать сайт или раскрыть секреты.

2. **Экономия запросов** — минимальные правки, не переписывай то, что работает.

3. **Качество кода** — соблюдай структуру, стиль, проверяй через `oxlint`.

4. **Скорость** — не делай лишних действий, не сканируй проект заново.

---

## 📋 Обязательные правила

- **Проверяй информацию по коду**, не доверяй чужим отчётам.

- **Лечи корень проблемы**, а не симптомы.

- **Перед изменением логики** — опиши план (2–4 пункта) и получи согласие.

- **Используй `edit_file`** вместо создания новых файлов, где это возможно.

- **Если задача не решилась с двух попыток** — прекрати и предложи поискать решение в интернете.

- **Не предлагай изменения, которых нет в коде**.

- **Не копируй весь проект в ответ** — ссылайся на файлы.

- **Не оставляй заглушек** в коде.

- Перед началом работы всегда просматривай `PLAN.md`, особенно раздел «Пожелания и планы владельца (бэклог)», чтобы предлагать решения, соответствующие моим целям.

**Важно:** пользователь не программист — объясняй логику простым языком.

---

## 🔄 Обновление документации

- **Агент обязан** обновлять `PLAN.md` при:
  - добавлении или удалении файлов/папок
  - изменении архитектуры или стека
  - появлении новых жёстких ограничений
  - смене зависимостей (package.json)
  - завершении задачи, которая меняет состояние проекта
- После внесения изменений в план — **сообщи пользователю**, что `PLAN.md` обновлён.
- Если изменение незначительное или ты не уверен — **спроси**, нужно ли обновлять план.

---

## 🧠 Выбор модели (экономия лимитов)

- **Koda Base** — для простых задач: ответы на вопросы, объяснение кода, быстрые правки.

- **Koda Pro** — только для сложных задач: рефакторинг, написание нового функционала, глубокий анализ.

- Не используй Koda Pro для простых задач — это тратит месячный лимит.

```bash

Не удаляй vite.config.js / package.json. / vercel.json.
```
