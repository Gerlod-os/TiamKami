## 1. СУТЬ ПРОЕКТА

Сайт-визитка Twitch-канала **Tiankami** — база рогаликов (~440 игр) с личными оценками, прогрессом и заметками стримера. Зрители узнают «во что поиграть», видят плейлисты прохождений и подборки; стример получает систематизированную библиотеку и бренд канала.

**Дизайн-концепция:** «уютный хардкор» — тёмная тема (#121212 → #1a1a2e), пастельные акценты (розовый #FFB6C1, фиолетовый #C9A0DC, голубой #A0C4FF), скругления 12–16px, свечение при наведении. Шрифты: Nunito (заголовки), Inter (текст). Маскоты: свои SVG-персонажи (геймпад с рожицей, герой в капюшоне) — в `src/assets/`.

### 3.3. Стратегия загрузки (stale-while-revalidate)

**Реализация:** `src/utils/loadData.js`

1. **МГНОВЕННО:** память → localStorage-кэш (ключ привязан к URL таблицы хэшем) → локальный `src/data/*.json`.
2. **В ФОНЕ:** сверка с таблицей (не чаще раза в 15 минут).
   - Загружается Оригинал (TSV) — базовые данные.
   - Если есть API-ключ — загружается Копия (Sheets API) для ссылок.
   - Fallback: если Копия не загрузилась — пробует Оригинал через Sheets API (формулы =HYPERLINK).
   - Merge: данные из Оригинал + ссылки из Копия (или fallback).
   - Обновление: добавляются новые игры, обновляются изменённые (кроме `steamAppId/image/steamUrl`), удаляются игры, которых нет в Оригинал.
3. **TTL кэша:** 6 часов.
4. **При недоступности localStorage:** работа из памяти и локального JSON.
5. **При фоновой проверке:** восстанавливаем `steamAppId` + обложки из старой версии, если Sheets API недоступен.

**Ключи кэша (в localStorage):**

- `tiankami_games_v4_<hash>`
- `tiankami_games_v4_<hash>_time`
- `tiankami_collections_v4_<hash>`
- `tiankami_collections_v4_<hash>_time`

**Функции публичного API:**

- `fetchGames({ onUpdate })` — возвращает игры, вызывает `onUpdate(свежие)` при изменении
- `fetchCollections({ onUpdate })` — аналогично
- `clearCache()` — полный сброс кэша (используется в FxPanel)

### 3.4. Обогащение данными

**Из локального JSON (`enrichFromLocalJson`):**

- Добавляет `image` (CDN Steam) и `steamUrl` по `steamAppId`.

**Из Копии (Sheets API):**

- Читает колонки C:W (C — название, U — Steam, V — YouTube, W — МИ).
- Сопоставляет по названию.
- Записывает в `games.json` три поля: `steamAppId`, `youtube`, `miVideo`.

**Из Оригинала (fallback):**

- Парсит формулы `=HYPERLINK("url";"label")` в колонке C (название) и в колонках V/W.

**YouTube-фильтрация:**

- Показываются только ссылки с канала стримера (`BRAND.youtubeChannelName`).
- Проверка через noembed (кэш бессрочный, лимит 20 проверок за сессию).

#### Утилиты (`utils/`)

**`normalize.js` — ЕДИНЫЙ НОРМАЛИЗАТОР (импортируется в runtime и sync-скрипт):**

- `normalizeStatus(raw)` — приводит статусы к каноническому виду:
  - "Жду релиз" → "Жду релиза"
  - "В процессе" → "В процессе"
  - "Пройдено", "Дропнуто", "Обзор" — без изменений
- `normalizeGames(rows)` — парсит TSV (колонки: Название, Жанр, Особенности, Сеттинг, Сложность, Наиграно (часы), Статус, Прогресс (%), Оценка (?/10), Дата выхода, Когда играл, Примечания, YouTube прохождение, Проводил МИ, Выпуск МИ)
  - Название — эвристика: пустой заголовок с данными или колонка 2 (fallback).
  - Картинка — колонка ПЕРЕД названием.
  - Сортировка по названию (русская локаль).
- `normalizeCollections(rows)` — **ПОСТРОЧНЫЙ** парсер подборок (не переписывать на колоночный!).
  - Алгоритм: для каждого заголовка подборки сканируем окно из 5 колонок, игра = первая текстовая ячейка, ранг = ближайшее число правее (до +4 колонок).
  - «ЗОЛОТОЙ СПИСОК» — без рангов (числа игнорируются принудительно).
- `isUrl(value)` — проверка на http(s)
- `extractHyperlinkParts(cell)` — парсит `=HYPERLINK("url";"label")`
- `isYouTubeUrl(url)` — regex
- `extractSteamAppId(url)` — извлекает appid из ссылки Steam
- `steamHeaderUrl(appId)` — CDN-обложка: `https://cdn.cloudflare.steamstatic.com/steam/apps/${appId}/header.jpg`

**`date.js`:**

- `parseRuDate(dateStr)` — парсит `DD.MM.YYYY` в Date (возвращает null при ошибке)

**`slugify.js`:**

- `slugify(title)` — транслитерация, удаление спецсимволов, замена пробелов на `-`
- `uniqueSlug(slug, usedSlugs)` — добавляет суффикс при коллизии

**`useCounter.js` — анимация счётчика:**

### 4.3. `scripts/`

**`sync-data.js` — синхронизация данных:**

- Читает `.env` вручную (через `fs`), т.к. в Node `import.meta.env` нет
- Загружает Оригинал (TSV) через `GAMES_URL`
- Загружает Копию (Sheets API) через серверный ключ (`SHEETS_API_KEY_SERVER`)
- Обогащает игры: `steamAppId`, `youtube`, `miVideo`
- Сохраняет в `src/data/games.json` и `collections.json`
- **Важно:** использует `valueRenderOption=UNFORMATTED_VALUE` для Копии (чтобы видеть чистые ссылки)

**`prerender.mjs` — SEO-пререндер (запускается после `vite build`):**

- Читает `src/data/games.json` и `collections.json`
- Генерирует `dist/index.html` (главная с мета-тегами)
- `dist/catalog.html` (каталог)
- `dist/collections.html` (подборки)
- Для каждой игры: `dist/catalog/<slug>/index.html` (с мета-тегами: название, жанр, оценка, примечания)
- `sitemap.xml` (все URL: главная, каталог, подборки, все игры)
- `robots.txt`

| N       | Примечания                               |                                                            |

| P       | Проводил МИ                              | TRUE/FALSE                                                 |
| Q       | Выпуск МИ                                | гиперссылка                                                |

### 5.2. Особенности парсинга

- **МИ** = «мастер Игорей» — многопользовательский интерактив, турнир стримеров. Признак — колонка «Проводил МИ» (TRUE/FALSE), видео — «Выпуск МИ».
- **Статус «Жду релиз»** → нормализуется в «Жду релиза» (`normalizeStatus`).
- **Ссылки** валидны только если начинаются с http(s) (`isUrl`); тексты-заглушки («Ссылка на плейлист») отфильтровываются.
- **YouTube-ссылки** показываются только с канала стримера (проверка author_name через noembed).
- **Steam:** никаких запросов к API — только CDN-обложка и ссылка по appid из гиперссылки в названии.
- **Подборки** парсятся ПОСТРОЧНО (колонки «гуляют») — не переписывать на колоночный.
- **«ЗОЛОТОЙ СПИСОК»** — без рангов (числа игнорируются принудительно).

### 5.3. Даты

- Только через `parseRuDate` (формат DD.MM.YYYY).
- Используется для сортировки по дате выхода и «Когда играл».
