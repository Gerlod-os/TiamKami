## Проект
Личная база рогаликов стримера TianKami.
Сайт должен работать из России, быть полностью бесплатным.
## Стек (строго)
- HTML + Vanilla JavaScript (без React, Vue, TypeScript, Next.js)
- Tailwind CSS через CDN
- Данные: data/games.json (уже есть ~440 игр)
- Хостинг: GitHub Pages
- Позже: Supabase (пока не трогать)
## Структура проекта
- index.html — главная страница (каталог)
- js/games.js — логика загрузки, фильтров и карточек
- data/games.json — все игры
- css/ — если понадобится
